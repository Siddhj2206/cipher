## Downloads

| System | File |
|---|---|
| Linux (any distro) | `Cipher-@VERSION@-linux-x86_64.AppImage`: make it executable and run it |
| Debian, Ubuntu | `Cipher-@VERSION@-linux-amd64.deb` |
| Fedora, openSUSE | `Cipher-@VERSION@-linux-x86_64.rpm` |
| Linux, by hand | `Cipher-@VERSION@-linux-x86_64.tar.gz`: unpack and run `./install.sh` (installs to `~/.local`) |
| Windows 10 and 11 | `Cipher-@VERSION@-windows-x64-setup.exe`, or the portable `.zip` |
| macOS 12 and later (Apple silicon and Intel) | `Cipher-@VERSION@-macos-universal.dmg` |

`SHA256SUMS.txt` lists every file's checksum.

**First launch on Windows and macOS.** Until the builds are code-signed, Windows SmartScreen says
the app is from an unknown publisher (More info → Run anyway), and macOS says it can't check the
app (right-click Cipher in Applications → Open, once).
